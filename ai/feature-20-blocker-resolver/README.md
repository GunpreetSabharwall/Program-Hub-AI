# Feature 20 — Blocker Resolver

## What It Does

When an issue is labeled `blocked` in a source repository, `risk-flag.yml` calls this script with the repository and issue number. The script fetches the issue title and description, retrieves the last 50 closed issues as context, and calls Claude to generate 2-3 specific resolution suggestions, a recommended owner, and a reference to a similar resolved issue if one exists. Posts the suggestions as a GitHub comment.

Can also be triggered manually via `workflow_dispatch` or called as a reusable workflow (`workflow_call`).

## Prompt

```
A GitHub issue has been labeled 'blocked'. Help resolve it.

Blocked issue:
Title: {issue_title}
Description: {issue_body}
Assignee: {assignee}

Recent closed issues in this repo (for context):
{closed_issues_list}

Provide:
1. 2-3 concrete resolution suggestions specific to this blocker
2. A recommended owner or team to contact
3. Reference to a similar resolved issue from the list above, if one exists

Format as a brief GitHub comment (markdown). Be specific and actionable.
```

## How to Enable

This feature is wired automatically into `risk-flag.yml`. When `risk-flag.yml` is deployed to a source repository and a `blocked` label is applied, the blocker resolver runs automatically.

To run manually:
```bash
OCTO_PAT=... ANTHROPIC_API_KEY=... python ai/feature-20-blocker-resolver/blocker-resolver.py octocat/example-app 42
```
